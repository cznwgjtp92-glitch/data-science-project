# Study Time and Academic Performance

**Author:** HE MENGELEI (MC660743)

## Research question
Does increased monthly study time correspond to higher average academic performance?

## Findings
Scores increase from 68 in January to 94 in October while study time rises from 12 to 35 hours. The scatter plot shows a positive association. This illustrative dataset does not prove causation.

## Reproduce
```bash
pip install -r requirements.txt
python analysis.py
```
